# Changelog

## 1.0.0 — 2026-09-06

- Initial static, framework-neutral release with no AI API or runtime dependencies.
- SVG graph editor, 18 node types, properties, connections, multi-selection, pan/zoom, keyboard movement and 60-step undo/redo.
- Full Catalan, Spanish and English interface, education, templates, findings and textual exports.
- IndexedDB project management and validated JSON round trips.
- SCC-based analyzer, contextual efficiency recommendations, budget and manual model prices.
- Structural simulation with decisions, parallel branches, bounded cycles and explicit incomplete outcomes.
- 14 templates including research/report and Plan → Execute → Verify.
- JSON, SVG, PNG, Mermaid, Markdown and printable HTML exports.
- Light/dark/system theme, onboarding, responsive layout and native accessible controls.
- IONOS deployment and user guides in three languages, source architecture, security review and test suites.
